## Guidance and notes

- The CSS variables are applied by `src/hooks/useTheme.js` from the per-theme definitions in `src/constants/themes.js`.
- Use the variable names (for example `var(--color-primary)`) in component styles so themes switch automatically.
- When adding new colors, choose a suggested font color (black or white) that provides a contrast ratio of at least ~4.5:1 for normal text. The samples above use a simple heuristic: dark swatches get white text, light swatches get black text.
- If you need precise WCAG contrast, compute relative luminance and contrast ratio for specific foreground/background pairs and pick the color that meets the threshold.

If you want, I can also generate a small helper React component (`ColorSwatch.jsx`) that renders these samples dynamically based on `src/constants/themes.js` so the doc stays in sync with the code.
