# Emergency Supply App - Main Menu

## Quick Actions
- Scan Barcode
- Add Item Manually

## Dashboard
- Completeness (DSB baseline progress)
- Total Items
- Expiring Soon

## Preparedness Checklist
- View DSB baseline requirements by category
- Track progress (Water, Food, Meds, First Aid, Hygiene, Warmth, Light, Documents, Tools)
- Set personal goals above/below government minimum

## Data & Sync
- Sync Status (online/offline indicator)
- Force Sync to Remote
- View Sync History
- Last Sync Time

## Settings
- **Household**
  - Number of persons in household
  - Contingency persons (buffer for extras)
  - Adjust recommended storage per person
  - Load default DSB baseline
- **Form Fields**
  - Edit/customize input form fields
  - Show/hide optional fields
- **Display**
  - Color Scheme (Light, Dark, Vibrant)
  - Language (EN/NO/DE)
  - Notifications (toggle expiry alerts)
- **Data Management**
  - Export Inventory (CSV/PDF)
  - Import Backup
  - Clear All Data (with confirmation)

## Account
- Login/Logout
- Change Password
- Delete Account (with confirmation)
